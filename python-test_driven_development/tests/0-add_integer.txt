This file contains doctests for the function add_integer.

The add_integer function adds two numbers and returns an integer.
Only integers and floats are accepted.
Floats are converted to integers before the addition.
If an invalid type is provided, a TypeError is raised.

>>> add_integer = __import__("0-add_integer").add_integer

Basic usage with integers.

>>> add_integer(1, 2)
3

>>> add_integer(100, -2)
98

If the second argument is omitted, it defaults to 98.

>>> add_integer(2)
100

Floats are accepted and converted to integers.

>>> add_integer(100.3, -2)
98

>>> add_integer(-5, -10)
-15

If the second argument is not an integer or a float,
a TypeError must be raised.
