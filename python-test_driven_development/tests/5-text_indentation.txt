This file contains doctests for the function text_indentation.

The text_indentation function prints text with 2 new lines after '.', '?', ':'.

>>> text_indentation = __import__("5-text_indentation").text_indentation

Basic usage with period.

>>> text_indentation("Hello. World")
Hello.
<BLANKLINE>
World

Basic usage with question mark.

>>> text_indentation("How are you? I am fine")
How are you?
<BLANKLINE>
I am fine

Basic usage with colon.

>>> text_indentation("Title: Content")
Title:
<BLANKLINE>
Content

Multiple delimiters.

>>> text_indentation("Hello. How are you? Good: thanks")
Hello.
<BLANKLINE>
How are you?
<BLANKLINE>
Good:
<BLANKLINE>
thanks

Spaces after delimiters are removed.

>>> text_indentation("Hello.   World")
Hello.
<BLANKLINE>
World

No delimiters.

>>> text_indentation("Hello World")
Hello World

Empty string.

>>> text_indentation("")

Delimiter at the end.

>>> text_indentation("Hello.")
Hello.
<BLANKLINE>

Multiple delimiters in a row.

>>> text_indentation("Test.?:")
Test.
<BLANKLINE>
?
<BLANKLINE>
:
<BLANKLINE>
