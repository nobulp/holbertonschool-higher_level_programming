This file contains doctests for the function matrix_divided.

The matrix_divided function divides all elements of a matrix by a number.
The result is a new matrix with values rounded to 2 decimal places.

>>> matrix_divided = __import__("2-matrix_divided").matrix_divided

Basic usage.

>>> matrix = [[1, 2, 3], [4, 5, 6]]
>>> matrix_divided(matrix, 3)
[[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

The original matrix must not be modified.

>>> matrix
[[1, 2, 3], [4, 5, 6]]

Floats are supported.

>>> matrix_divided([[1.5, 2.5]], 2)
[[0.75, 1.25]]

Matrix must be a list of lists.
