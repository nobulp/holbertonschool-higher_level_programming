# JavaScript Warm Up

This directory contains introductory JavaScript exercises for the Holberton School higher-level programming curriculum.

## Objectives

- Discover the basics of JavaScript syntax
- Declare variables with `const` and `let`
- Print output with `console.log(...)`
- Execute JavaScript files with Node.js
- Follow project style requirements

## Requirements

- Ubuntu 20.04 LTS
- Node.js
- `semistandard`
- All scripts must be executable
- No use of `var`

## Run

```bash
./0-javascript_is_amazing.js
```

## Check style

```bash
semistandard *.js
```

## Files

- `0-javascript_is_amazing.js`: prints `JavaScript is amazing`
