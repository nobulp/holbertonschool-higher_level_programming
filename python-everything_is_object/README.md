# Python Everything Is Object

This directory contains exercises about Python objects, types, and references.

## Objectives

- Understand that everything in Python is an object
- Identify the type of an object
- Answer conceptual questions in text files

## Requirements

- Ubuntu 20.04 LTS
- Python 3
- Answers must be written exactly as requested

## Files

- `0-answer.txt`: contains the function name used to print the type of an object
